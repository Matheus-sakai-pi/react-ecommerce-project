# 🛒 Loja do Matheus - E-commerce React

Aplicação de e-commerce desenvolvida em React para listagem de produtos, busca em tempo real, ordenação por preço e gestão de carrinho de compras.

## 🚀 Tecnologias Utilizadas
- React.js (Hooks: `useState`, `useEffect`)
- CSS3 (Flexbox & CSS Grid)
- JavaScript (ES6+)
- API DummyJSON (Consumo de dados via Fetch API)

## ✨ Funcionalidades
- Consumo e exibição de produtos via API externa.
- Busca em tempo real por nome do produto.
- Ordenação de produtos por menor e maior preço.
- Carrinho de compras lateral interativo (adicionar, remover e alterar quantidade).
- Cálculo automático do valor total do carrinho.
- Layout responsivo.
